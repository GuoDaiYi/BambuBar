# BambuBar 2.0.1

## What's new

- **Smaller monitor window** — reduced from `590 × 340` to `560 × 325`, with less horizontal padding and no empty strip below the footer.
- **Smaller settings panel** — `560 × 300`, matching the compact monitor.
- **Cleaner account row** — sign-out is now an icon button, so the account email and UID no longer truncate.
- **All read-only monitor behavior from 2.0.0 is unchanged** — progress, layers, ETA, download/unpack phases, read-only temperatures, update checks, auto-hide and monochrome notifications.

## Install

Download `BambuBar-2.0.1-macOS.dmg`, open it, and drag **BambuBar** into **Applications**.

# BambuBar 2.0.1（中文）

## 本次更新

- **监控窗口更小**：从 `590 × 340` 缩小到 `560 × 325`，左右内边距收紧，底部不再留空。
- **设置面板更小**：`560 × 300`，与监控面板一致。
- **账号行优化**：退出登录改成图标按钮，邮箱和 UID 不再被截断。
- **只读监控功能保持不变**：进度、层数、预计时间、下载/解压阶段、只读温度、更新检查、自动收回和单色通知。

## 安装

下载 `BambuBar-2.0.1-macOS.dmg`，打开后把 **BambuBar** 拖进 **Applications**。
